# Pomodoro Timer

A simple Pomodoro Timer built with HTML, CSS, and JavaScript to help you organize focused work sessions and breaks.

Live site: [Pomodoro Timer](https://outofbluee.github.io/pomodoro-timer/)

## Features

- Pomodoro, short break, and long break timer modes.
- Start, pause, and reset controls.
- Automatic switching between focus sessions and breaks.
- Custom settings for Pomodoro, short break, and long break durations.
- Configurable long break interval.
- Optional auto-start for breaks and Pomodoro sessions.
- Audio feedback for button clicks and completed sessions.
- Timer status shown in the browser tab title.

## How to Use

1. Open the [Pomodoro Timer](https://outofbluee.github.io/pomodoro-timer/).
2. Choose a timer mode: `Pomodoro`, `Short Break`, or `Long Break`.
3. Click `Start` to begin the timer.
4. Use `Pause` to temporarily stop the countdown.
5. Use `Reset` to restart the current session.
6. When a Pomodoro session ends, the app automatically switches to a break. After the configured number of Pomodoro sessions, it switches to a long break.

## Settings

Click the gear button to customize:

- Pomodoro duration.
- Short break duration.
- Long break duration.
- Long break interval.
- Auto-start breaks.
- Auto-start Pomodoro sessions.

After changing the settings, click `Submit` to apply them.

## Running Locally

Clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/outofbluee/pomodoro-timer.git
cd pomodoro-timer
```

No build step is required.
